# Code of Conduct

OAI Bot should be a place where people can disagree about product behavior, architecture, and code without making the work hostile.

Be direct about the problem and respectful toward the person. Harassment, threats, discriminatory abuse, deliberate disruption, or publishing someone else's private information are not acceptable in project spaces.

Maintainers may edit or remove contributions, comments, or accounts that violate these expectations. Report a problem privately using the process in [SECURITY.md](SECURITY.md) when a public issue would expose someone or make the situation worse.
