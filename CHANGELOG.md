## 0.2.0 (2026-08-30)

- Added persistent VM-home Bot data with Grok-compatible profiles, memory logs, routines, transcripts, and real per-Bot SQLite stores.
- Added hidden routine runners, completion handoff, priority peer routing, cross-conversation user interruption, and skipped-question recovery.
- Added the polished per-Bot information pane, runtime and routine surfaces, responsive interaction improvements, and stable useful-only activity indicators.
- Added a single package-sourced version shown in the application UI.
